# 项目结构

```text
src/          登录、课程解析、协议、运行器和状态管理
webui/        页面、HTTP API、SSE 和飞牛网关入口
fnos/         飞牛清单、权限、生命周期脚本和图标
test/         协议、扫描、队列、统计、多用户及验证码回归
docs/         结构说明
```

## 后端

- `auth.mjs`：生成二维码、轮询并核验会话。
- `http.mjs`：Cookie、跳转、请求超时及会话加密存储。
- `catalog.mjs`：课程目录、任务卡片、完成标记和媒体元数据。
- `protocol.mjs`：视频事件与文档任务请求，校验必要参数。
- `runner.mjs`：计时、暂停、继续、停止和视频异常状态。
- `controller.mjs`：选课、扫描和运行队列，协调验证码恢复及快照。
- `challenge.mjs`：展示平台验证码并提交本人输入。
- `state.mjs`：保存课程、任务、选课和日志；不保存任务签名 URL。

## 运行流程

扫码或验证已有会话 → 选课 → 按需扫描章节 → 刷新任务卡片 → 跳过已完成任务 → 执行所选任务 → 重读平台状态 → 保存快照。

目录和媒体信息在扫描时读取，统计不必等任务执行。参考资料不计入任务点。空课程与空章节可跳过，普通章节读取失败不阻断后续扫描。

9010 验证会保留当前队列，等待本人输入；通过后重试被拦截的操作。停止会取消续接。重启后缓存先标记待复核，执行前重新获取平台状态和断点。

## 页面与飞牛

`server.mjs` 提供本机 HTTP API 和 SSE。`native-client.js` 将后端快照转换为页面数据；`app.js` 负责选课、章节树、筛选和进度显示。

`fnos.mjs` 从统一网关获取可信 NAS UID，为每个用户分配独立控制器、会话、存储与事件流。后端使用 Unix Socket，不直接开放共享管理端口。

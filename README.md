# 超星学习控制台

面向个人和飞牛 NAS 的学习任务管理工具。纯 HTTP 后端，无 Chromium、视频播放器或解码依赖。

支持扫码登录、选课、章节扫描、视频和文档任务、实时进度、暂停/继续/停止、断点续接。飞牛版按 NAS 用户隔离会话和任务。

## 飞牛安装

在 [Releases](https://github.com/liuayueeryuan0313/chaoxing-study-native/releases) 下载最新版 ARM64 FPK，通过应用中心手动安装。要求 fnOS 1.1.3100 或更新版本，暂不提供 x86 安装包。

首次打开用学习通 App 扫码。勾选课程，点击“开始学习”即可自动扫描并执行；支持仅视频、仅课件和单节运行。默认 2 倍速，任务禁止倍速时使用 1 倍。

升级时保留应用数据，完成后重新打开应用页面。关闭网页不影响后台队列；停止服务请在飞牛应用中心操作。

## 本机运行

需要 Node.js 22.19 或更新版本。

```sh
npm ci
npm test
npm start
```

访问 http://127.0.0.1:3001/ 。本机入口为单用户模式；飞牛多用户入口为 `webui/fnos.mjs`。

## 进度与限制

界面分别显示本地估算、已提交位置和平台保存位置。完成状态由重新读取的任务卡片确认；本地进度到 100% 不代表平台已通过。

视频任务采用 HTTP 协议模拟，不是真实浏览器播放。平台验证码需本人处理，通过后从原位置继续。真正截取的片段视频、人脸验证、直播、测验、作业和考试尚未适配。

会话加密保存在本机运行目录，仓库和安装包不含账号数据。`session.enc` 和 `session.key` 均不应分享。
